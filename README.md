# Bat-To-Exe-Conventer
English version
Bat2Exe CLI Converter
A simple and effective command-line tool written in Python that converts Windows batch scripts (.bat or .cmd) into standalone executable files (.exe) using PyInstaller.

The tool automatically bundles the script with secure encoding, supports custom icons (.ico), and allows you to hide the black console window when the generated program runs.

Wersja polska
Bat2Exe CLI Converter
Proste i skuteczne narzędzie wiersza poleceń (CLI) napisanego w Pythonie, które konwertuje skrypty wsadowe Windows (.bat lub .cmd) na niezależne pliki wykonywalne (.exe) przy użyciu PyInstallera.

Narzędzie automatycznie pakuje skrypt wraz z bezpiecznym kodowaniem, obsługuje opcjonalne ikony (.ico) oraz pozwala na ukrycie czarnego okna konsoli podczas uruchamiania wygenerowanego programu.
